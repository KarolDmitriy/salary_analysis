# Salary Analysis Russia

Анализ зарплат по регионам России.  
Скрипт читает CSV-файл, считает среднюю, максимальную и минимальную зарплату, сохраняет итоги в Excel и строит график.

## Как использовать
1. Склонировать репозиторий
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
