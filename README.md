# 📊 Salary Analysis Russia

Аналитика уровня заработных плат по регионам Российской Федерации с помощью Python.  
Проект показывает умение работать с данными, строить визуализации и формировать аналитические отчёты.

---

## 💡 Цель проекта
Изучить различия в уровне зарплат по регионам РФ, определить регионы с самыми высокими и низкими доходами и визуализировать результаты для наглядного сравнения.

---

## 🚀 Основные функции
- Чтение данных из CSV (`data/salaries.csv`);
- Подсчёт средней, минимальной и максимальной зарплаты;
- Экспорт результатов в Excel (`output/results.xlsx`);
- Построение диаграммы (`output/charts.png`);
- Лёгкое добавление новых данных.

---

## ⚙️ Используемые технологии
- Python 3.11+
- pandas — анализ и обработка данных
- matplotlib — визуализация
- openpyxl — экспорт в Excel
- pathlib — работа с путями

---

## 🧰 Как запустить проект

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Проверьте наличие файла `data/salaries.csv`, например:
```csv
region,salary
Москва,95000
Санкт-Петербург,78000
Новосибирская область,62000
Липецкая область,52000
```

3. Запустите проект:
```bash
python main.py
```

4. Итоги сохранятся в папке `output/`:
- `results.xlsx` — Excel-таблица;
- `charts.png` — график.
